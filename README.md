# BMP MODS
Статический сайт для GitHub Pages, без сборки и сторонних зависимостей.

## Запуск
В папке проекта: `python -m http.server 8000`, затем открыть http://localhost:8000.

## Публикация
Создайте публичный репозиторий bmp-mods, загрузите все файлы проекта в main.
Settings → Pages → Deploy from a branch → main → / (root).
Адрес: https://BMProd-FS.github.io/bmp-mods/.

## Управление
Откройте #admin. Для публикации укажите owner/repository и fine-grained GitHub token с Contents: Read and write только для этого репозитория. Токен хранится только в памяти вкладки. Используются прямые запросы к GitHub API. Автоматическое обновление Pages после сохранения занимает некоторое время.
Редактирование и экспорт JSON доступны без токена. Локальный черновик не изменяет публичный каталог. Перед подключением удалите примеры или заполните их: придуманных версий и ссылок скачивания нет.
Обложки/скриншоты: URL HTTPS либо пути к изображениям в репозитории. Загрузка файлов через админку пока не реализована. ZIP модов хранится на файлообменниках.
Скрытие карточки убирает её из каталога, но данные остаются в публичном репозитории.
При конфликте обновлений публикация останавливается: экспортируйте черновик, обновите страницу и перенесите изменения.
